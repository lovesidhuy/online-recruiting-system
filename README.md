# Online Recruiting System

A web application for managing job postings, applicants, and the hiring process.

## Features

*   Admin dashboard for managing HR accounts, job categories, and viewing reports.
*   HR dashboard for posting and managing job listings.
*   Applicant dashboard for searching and applying for jobs.
*   AI-powered screening of applicants.

## Installation

1.  Clone the repository:
2.  Import the `database/ors.sql` file into your MySQL database.
3.  Configure the database connection in `config/bootstrap.php`. The default credentials are:
    *   **Database:** ors
4.  Install the dependencies:
    ```bash
    npm install
    ```
5.  Start the PHP server:
    ```bash
    php -S localhost:8000
    ```
6.  Start the Node.js server:
    ```bash
    node lang.js
    ```

## Usage

*   Access the application at `http://localhost:8000`.
